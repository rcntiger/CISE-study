1인간공학 개요
  • 정의
    인간의 특성과 한계를 고려해
    기계·작업·환경을 인간에게 맞추는 학문
    (사람을 기계에 맞추는 것이 아님)
  • 목적
    안전성 향상, 사고 방지
    작업 능률·생산성 향상
    쾌적성·만족도 향상
  • 차파니스(Chapanis)
    인간공학 정의로 자주 나오는 학자

⭐ 인간 vs 기계의 장점

  • 인간이 우수
    예기치 못한 사건 감지
    귀납적 추리, 융통성
    경험 활용, 원칙 적용
    낮은 수준의 자극 감지
  • 기계가 우수
    연역적 추리, 반복 작업
    장시간 일관된 작업
    빠르고 큰 힘, 정량적 정보 처리
    여러 작업 동시 수행

인간공학 연구 기준(평가 척도)의 요건

  • 적절성(타당성)
  • 무오염성
  • 신뢰성(반복성)
  • 민감도
2인간-기계 체계
  • 수동 체계
    인간이 동력원 + 제어
    수공구 사용
  • 기계화 체계(반자동)
    동력은 기계, 제어는 인간
    예: 자동차 운전
  • 자동 체계
    기계가 감지·결정·실행
    인간은 감시·보전·프로그램

인간-기계 체계의 기본 기능

감지(정보 입력)
→ 정보 보관(저장)
→ 정보 처리·의사결정
→ 행동

체계 설계 순서

  • 1. 목표·성능 명세 결정
  • 2. 체계 정의
  • 3. 기본 설계 (기능 할당, 작업 설계)
  • 4. 계면(인터페이스) 설계
  • 5. 촉진물 설계
  • 6. 시험·평가
3정보이론
  • 정보량 단위: bit
  • 같은 확률 대안 n개
    H = log₂ n
  • 확률이 다른 경우
    H = Σ p × log₂(1/p)

예) 대안 8개 동일 확률
→ log₂ 8 = 3 bit

예) 확률 0.5, 0.25, 0.25
→ 0.5×1 + 0.25×2 + 0.25×2
= 1.5 bit

  • 힉-하이만 법칙
    반응시간은 자극 정보량에 비례
    RT = a + b·H
  • 피츠 법칙
    동작시간은 거리가 멀고
    목표가 작을수록 증가
    MT = a + b·log₂(2D/W)
4표시장치

정량적 표시장치

  • 동침형: 눈금 고정, 지침 이동
    변화 방향·속도 파악에 유리
  • 동목형: 지침 고정, 눈금 이동
    표시 범위가 넓을 때
  • 계수형(디지털): 정확한 값 읽기에
    가장 유리 (판독 오차 적음)

정성적 표시장치
상태(정상·위험), 변화 추세 확인
색 구간 표시 활용

⭐ 시각 vs 청각 표시장치 선택

  • 청각이 유리
    메시지가 짧고 단순
    즉각 행동 요구
    시간적 사건 표시
    수신자가 자주 움직임
    조명이 어둡거나 시각 과부하
  • 시각이 유리
    메시지가 길고 복잡
    나중에 다시 참조
    공간적 위치 표시
    즉각 행동 불필요
    소음이 심한 장소

암호화(코딩) 요건
검출성, 판별성, 양립성,
부호의 의미, 표준화, 다차원 암호

5청각과 소음
  • dB(음압수준)
    SPL = 20 log(P/P₀)
  • 거리와 음압
    거리 2배 → 약 6dB 감소
    dB₂ = dB₁ − 20 log(d₂/d₁)
  • phon
    1,000Hz 순음 기준 음의 크기 수준
    (40phon = 1,000Hz 40dB와 같은 크기)
  • sone
    음의 크기 단위
    40phon = 1sone
    10phon 증가 → sone 2배
    sone = 2^((phon − 40)/10)

예) 60phon → 2^2 = 4sone

  • 은폐(masking)
    한 음 때문에 다른 음이
    잘 안 들리는 현상
  • 가청 범위: 20~20,000Hz
    민감한 영역 500~3,000Hz
  • 경보음 설계
    장거리(300m 이상): 1,000Hz 이하
    장애물·칸막이 통과: 500Hz 이하

소음 노출 기준 (시험 전 확인)

  • 8시간 90dB(A)
  • 5dB 증가 시 허용시간 절반
    95dB 4시간, 100dB 2시간
  • 충격소음 최대 140dB(A)
  • 소음작업: 8시간 85dB 이상
6조종장치와 양립성

⭐ C/R비 (조종-반응 비율)
조종장치 이동량 ÷ 표시장치 이동량

  • 회전형 C/R비
    (a/360 × 2πL) ÷ 표시장치 이동거리
    a: 회전각, L: 반지름
  • C/R비 작음 (민감)
    이동시간 짧음, 조정시간 김
  • C/R비 큼 (둔감)
    이동시간 김, 조정시간 짧음
  • 최적 C/R비: 두 시간의 합이 최소

예) 반지름 10cm 노브를 30° 돌릴 때
지침 1cm 이동
→ (30/360 × 2π × 10) ÷ 1
≈ 5.24

⭐ 양립성 종류

  • 개념적: 의미가 기대와 일치
    (빨강 = 정지, 위험)
  • 공간적: 위치 배치 일치
    (왼쪽 버튼 → 왼쪽 표시)
  • 운동적: 움직임 방향 일치
    (오른쪽으로 돌리면 증가)
  • 양식(modality): 청각 자극 → 음성 응답

조종장치 코딩 방법
형상, 크기, 색, 촉감, 위치, 조작법

7휴먼에러

⭐ 스웨인(Swain)의 분류 (행위적 관점)

  • 생략 오류(omission)
    필요한 작업을 빠뜨림
  • 실행 오류(commission)
    작업을 잘못 수행
  • 순서 오류(sequential)
    순서를 틀림
  • 시간 오류(time)
    너무 빠르거나 늦음
  • 불필요한 행동(extraneous)
    하지 않아도 될 일을 함

⭐ 리즌·라스무센 분류 (원인적 관점)

  • 착오(mistake)
    상황 해석·목표 설정이 잘못됨
    (계획 자체 오류)
  • 실수(slip)
    의도는 맞는데 실행을 잘못함
  • 건망(lapse)
    기억 실패로 잊어버림
  • 위반(violation)
    알면서 규칙을 어김

라스무센의 행동 수준

  • 숙련 기반(skill)
  • 규칙 기반(rule)
  • 지식 기반(knowledge)

대책
배타설계(실수 불가능하게)
→ 보호설계(풀프루프)
→ 안전설계(페일세이프)

  • 풀프루프: 잘못 조작해도 사고가 안 남
    (인터록 등)
  • 페일세이프: 고장 나도
    안전한 쪽으로 작동

인간 신뢰도 분석 기법
THERP, 휴먼에러율 예측
HEP = 오류 수 ÷ 오류 기회 수

8신뢰도 계산

계산 문제 단골입니다.

  • 직렬
    R = R₁ × R₂ × … × Rₙ
  • 병렬
    R = 1 − (1−R₁)(1−R₂)…(1−Rₙ)

예) 0.9 직렬 2개 → 0.81
예) 0.9 병렬 2개 → 1 − 0.01 = 0.99

  • n중 k 구조
    n개 중 k개 이상 작동하면 정상
  • 고장률 λ
    고장 건수 ÷ 총 가동시간
  • MTBF = 1/λ
    (수리 가능, 평균 고장 간격)
  • MTTF: 수리 불가, 고장까지 평균시간
  • MTTR: 평균 수리시간
  • 가용도
    MTBF ÷ (MTBF + MTTR)
  • 지수분포 신뢰도
    R(t) = e^(−λt)
  • 병렬 n개 MTTF
    MTTF × (1 + 1/2 + … + 1/n)
  • 직렬 n개 MTTF
    MTTF ÷ n

⭐ 욕조곡선

  • 초기고장: 고장률 감소
    디버깅, 번인(burn-in)으로 줄임
  • 우발고장: 고장률 일정
    예측 불가, 안전계수 고려
  • 마모고장: 고장률 증가
    예방보전(PM)으로 대응
9시스템 안전 기법

⭐ 시스템 수명주기 단계
구상 → 정의 → 개발 → 생산 → 운용 → 폐기

  • PHA (예비위험분석)
    구상 단계, 최초로 실시
    정성적
    위험 범주: 파국적 → 중대
    → 한계적 → 무시가능
  • FHA (결함위험분석)
    서브시스템 분석,
    여러 업체가 나눠 개발할 때
  • FMEA (고장형태와 영향분석)
    부품·요소의 고장 형태별 영향 검토
    정성적, 귀납적
    단점: 인적 원인·
    2개 이상 동시 고장 분석 곤란
  • CA (위험도 분석)
    고장의 위험도(치명도)를 정량 평가
    FMECA = FMEA + CA
  • ETA (사건수 분석)
    초기 사건에서 성공·실패로 갈라지며
    결과를 추적, 귀납적, 정량적
  • FTA (결함수 분석)
    정상(톱)사상에서 원인을 찾아 내려감
    연역적, 정량적
  • HAZOP (위험과 운전분석)
    화학공정 이탈을 가이드워드로 검토
  • MORT
    관리·설계·생산·보전 전반의
    안전 확보, FTA와 같은 논리 사용
  • THERP
    인간 실수율 예측 (정량적)
  • OSHA(운용위험분석)
    운용·보전 단계 위험 분석

위험 범주 (MIL-STD-882)

  • Ⅰ 파국적
  • Ⅱ 위기적(중대)
  • Ⅲ 한계적
  • Ⅳ 무시가능
10HAZOP 가이드워드
  • No / Not: 설계 의도의 완전한 부정
  • More / Less: 양의 증가·감소
  • As well as: 성질상 증가
    (다른 것이 추가됨)
  • Part of: 성질상 감소
    (일부만 달성)
  • Reverse: 반대 방향
  • Other than: 완전한 대체

HAZOP 전제조건

  • 두 개 이상 기기 고장이나
    사고는 동시에 일어나지 않음
  • 조작자는 위험 상황에서
    필요한 조치를 취함
  • 안전장치는 필요할 때 작동
11FTA (결함수 분석)

⭐ 주요 기호

  • 직사각형: 결함사상(중간사상)
  • 원: 기본사상 (더 분해 안 함)
  • 마름모: 생략사상 (정보 부족)
  • 집 모양: 통상사상 (정상적으로 발생)
  • 삼각형: 전이기호 (in/out)

⭐ 게이트

  • AND 게이트
    입력이 모두 발생해야 출력
    P = P₁ × P₂
  • OR 게이트
    입력 중 하나만 발생해도 출력
    P = 1 − (1−P₁)(1−P₂)
  • 억제 게이트: 조건 만족 시 출력
  • 우선적 AND: 순서대로 발생 시
  • 조합 AND: 3개 중 2개 등
  • 배타적 OR: 2개 이상 동시면 출력 없음

예) AND 게이트 입력 0.1, 0.2
→ 0.02
예) OR 게이트 입력 0.1, 0.2
→ 1 − 0.9 × 0.8 = 0.28

⭐ 컷셋과 패스셋

  • 컷셋: 동시에 발생하면
    정상사상을 일으키는 기본사상 집합
  • 최소 컷셋
    필요 최소한의 컷셋
    → 시스템의 위험성을 나타냄
  • 패스셋: 발생하지 않으면
    정상사상이 일어나지 않는 집합
  • 최소 패스셋
    → 시스템의 신뢰성을 나타냄
  • 구하는 법: 퍼셀(MOCUS) 알고리즘
    AND는 가로, OR는 세로로 전개
  • 불 대수: A·A = A, A + A·B = A

FTA 순서

  • 1. 정상사상 선정
  • 2. 사상별 재해 원인 규명
  • 3. FT도 작성
  • 4. 개선계획 작성
  • 5. 개선안 실시
12인체측정과 작업공간

⭐ 인체측정치 설계 원칙

  • 조절식 설계 (1순위)
    5~95% 범위 조절
    예: 의자 높이, 자동차 좌석
  • 극단치 설계
    최대치(95%): 출입문 높이,
    비상구, 통로 폭
    최소치(5%): 조종장치 거리,
    선반 높이, 버튼 누르는 힘
  • 평균치 설계 (최후)
    예: 은행 창구, 공공장소 의자

측정 방법

  • 구조적(정적): 정지 자세
  • 기능적(동적): 움직이는 자세

작업대 높이

  • 정밀 작업: 팔꿈치보다 5~10cm 높게
  • 일반(경) 작업: 팔꿈치보다
    5~10cm 낮게
  • 힘든(중) 작업: 팔꿈치보다
    10~20cm 낮게

작업 영역

  • 정상 작업역: 위팔을 붙이고
    아래팔만 뻗은 범위
  • 최대 작업역: 팔 전체를 뻗은 범위

⭐ 부품 배치 4원칙
중요성, 사용빈도
(위치 결정)
기능별, 사용순서
(배열 결정)

13작업생리와 작업환경

⭐ 에너지대사율 (RMR)
(작업 시 소비에너지 − 안정 시)
÷ 기초대사량

  • 0~2: 경작업
  • 2~4: 중(中)작업
  • 4~7: 중(重)작업
  • 7 이상: 초중작업
  • 산소부채
    작업 후에도 산소 소비가
    높게 유지되는 현상
  • 1L 산소 소비 ≈ 5kcal

⭐ 조도와 반사율
