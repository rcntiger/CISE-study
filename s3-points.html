CHAPTER 01기계공정의 안전, 기계안전시설 관리
1기계의 위험점
📋 출제기준 1-2 기계의 위험 안전조건 분석 · 4-2 안전시설 설치하기

"어떤 위험점인가?" 형태로 매회 나옵니다.

  • 협착점
    왕복운동 부분 + 고정 부분 사이
    예: 프레스 금형, 전단기 누름판
  • 끼임점
    회전운동 부분 + 고정 부분 사이
    예: 연삭숫돌과 작업대,
    교반기 날개와 하우징
  • 절단점
    회전하는 운동부 자체의 날
    예: 밀링 커터, 둥근톱 날
  • 물림점
    서로 반대로 맞물려 도는 두 회전체
    예: 롤러와 롤러, 기어와 기어
  • 접선물림점
    회전부의 접선 방향으로 물려 들어감
    예: 벨트와 풀리, 체인과 스프로킷,
    랙과 피니언
  • 회전말림점
    돌출된 회전체에 옷·머리카락이 말림
    예: 회전축, 드릴, 커플링
🧠 연상 암기협·끼·절·물·접·회 — 왕복+고정 = 협착, 회전+고정 = 끼임, 날 자체 = 절단, 회전+회전 = 물림, 벨트·풀리 = 접선물림, 축에 감김 = 회전말림

기계설비 위험요인 4가지
회전운동, 횡축운동, 왕복운동, 진동운동

🆕 보강 · 예시로 구분하기

  • 보기 예시 → 위험점
    프레스 금형 → 협착점
    연삭숫돌과 작업대 → 끼임점
    둥근톱 날 → 절단점
    롤러와 롤러 → 물림점
    벨트와 풀리 → 접선물림점
    회전축·드릴 → 회전말림점
  • 운동 형태별 예
    회전운동: 기어, 풀리, 플라이휠
    횡축운동: 벨트컨베이어 등 수평 이동
    왕복운동: 프레스 슬라이드, 셰이퍼
    진동운동: 진동 체, 착암기
  • 🔀 헷갈리는 선지고정부 + 회전부는
    끼임점, 고정부 + 왕복부는
    협착점입니다.
2방호장치와 안전설계
📋 출제기준 1-2 기계의 위험 안전조건 분석 · 4-1 안전시설 관리 계획하기

방호장치 분류

  • 격리형
    위험점 주위를 덮개·울로 차단
    예: 완전차단형, 덮개형, 안전방책
  • 위치제한형
    손을 위험 범위 밖에 두게 함
    예: 프레스 양수조작식
  • 접근거부형
    다가오는 신체를 밀어내거나 끌어냄
    예: 손쳐내기식, 수인식
  • 접근반응형
    신체가 들어오면 감지해 정지
    예: 광전자식
  • 포집형
    튀거나 날아오는 위험원을 잡아 둠
    예: 연삭숫돌 덮개, 반발예방장치

풀프루프와 페일세이프 ⭐

  • 풀프루프(Fool proof)
    사람이 실수해도 안전
    예: 인터록, 가드, 양수조작
  • 페일세이프(Fail safe)
    기계가 고장 나도 안전 쪽으로 동작
    • Fail passive: 고장 시 정지 (일반적)
    • Fail active: 경보 + 짧은 시간 운전
    • Fail operational: 병렬 계통으로
      다음 정비까지 운전 계속 (가장 바람직)

기계설비의 안전조건

외형, 기능, 구조, 작업, 보전 안전화

고장률 욕조곡선

  • 초기고장: 고장률 감소 (디버깅·번인)
  • 우발고장: 고장률 일정
  • 마모고장: 고장률 증가 (예방보전)

🆕 보강 · 가드 종류와 안전조건 뜻

  • 가드 종류
    고정 가드: 공구 없이는 못 엶
    조정 가드: 가공물에 맞게 조절
    연동(인터록) 가드: 열면 기계 정지
    경고 가드: 접근을 알려 줌
  • 안전조건 5가지의 뜻
    외형: 덮개·울, 색채, 구획
    기능: 오동작 방지, 페일세이프
    구조: 재료·설계·가공 결함 제거
    작업: 작업 방법·환경 개선
    보전: 점검·교환이 쉽게
  • 방호장치 해체 금지
    해체가 필요하면 사업주 허가,
    사유가 끝나면 즉시 원상 복구
3안전율
📋 출제기준 1-2 기계의 위험 안전조건 분석
  • 안전율
    = 인장강도(극한강도) ÷ 허용응력
    = 파괴하중 ÷ 최대사용하중
  • 안전율은 항상 1보다 큼
  • 허용응력 = 인장강도 ÷ 안전율

예) 인장강도 400MPa, 허용응력 100MPa
→ 안전율 = 4

예) 파괴하중 2,000kg, 안전율 5
→ 최대사용하중 = 400kg

응력
σ = 하중(W) ÷ 단면적(A)

🆕 보강 · 하중별 안전율과 와이어로프

  • 하중 종류별 안전율 크기
    정하중 < 반복하중
    < 교번하중 < 충격하중
    (충격하중일수록 크게 잡음)
  • 안전율을 정할 때 고려
    재료의 균질성, 하중 추정 정확도,
    응력 계산 정확도, 사용 조건
    (충격·온도·부식)
  • 와이어로프 안전율
    S = 로프 가닥수 × 파단하중
    ÷ 최대 사용하중
  • 예) 파단하중 4톤 로프 2가닥,
    하중 1.6톤 → 2 × 4 ÷ 1.6 = 5

기계공정의 특수성 분석

  • 설비 도면·장비사양서를 검토해
    위험요인과 안전지침을 도출
  • 통계적 원인분석 도구
    파레토도, 특성요인도, 클로즈 분석,
    관리도 (1과목 기출포인트 3번 주제 참고)
  • 공정도로 작업 흐름을 분석
    (2과목 '작업관리와 개선 절차' 참고)

표준안전작업절차서(SOP)
작업 순서별로 위험요인과
안전조치, 필요한 보호구를 적은 문서

특수 작업의 조건 예
밀폐공간, 고열·고압, 고소,
중량물 취급, 유해물질 취급

⭐ ISO 12100 위험 감소 3단계
(기계류 안전 설계 일반원칙)

  • 1. 본질적 안전설계
    위험원을 설계로 없애거나 줄임
  • 2. 안전방호·보완 방호조치
    가드, 방호장치, 비상정지
  • 3. 사용상 정보
    경고 표지, 사용설명서, 교육

본질적 안전
작업자가 실수하거나 기계가 고장 나도
안전이 확보되는 상태
(풀프루프·페일세이프, 2번 주제)

🆕 보강 · 위험성 평가 흐름 (ISO 12100)

기계의 위험성 평가 순서

  • 1. 기계의 제한 사양 결정
    (용도, 공간, 수명)
  • 2. 위험원 식별
  • 3. 위험성 추정
  • 4. 위험성 평가(허용 여부 판단)
  • 5. 위험성 감소 (3단계 방법)
  • 3단계 방법 순서가 중요
    설계로 해결 → 방호 → 정보 제공
    뒤 단계는 앞 단계로 못 줄인
    위험에만 사용
  • 🔀 헷갈리는 선지경고 표지·교육은
    마지막(3단계) 수단입니다.

재해조사의 목적
같은 재해·비슷한 재해의 재발 방지
(책임 추궁이 목적이 아님)

⭐ 재해 발생 시 조치 순서

  • 1. 산업재해 발생
  • 2. 긴급처리
  • 3. 재해조사
  • 4. 원인 분석
  • 5. 대책 수립
  • 6. 대책 실시 계획
  • 7. 실시
  • 8. 평가

⭐ 긴급처리 순서

  • 1. 피재 기계의 정지
  • 2. 피재자 구출·응급조치
  • 3. 관계자에게 통보
  • 4. 2차 재해 방지
  • 5. 현장 보존

재해조사 시 유의사항

  • 사실을 있는 그대로 수집
  • 목격자 증언은 사실과 추측을 구분
  • 조사는 신속하게, 2인 이상이 실시
  • 책임 추궁보다 재발 방지 우선
  • 피해자·관계자 진술을 폭넓게 들음

재해조사 순서와 통계적 원인분석은
1과목 기출포인트 3번 주제 참고

🆕 보강 · 사례연구 순서와 상해 종류

⭐ 재해 사례연구 순서

  • 전제조건: 재해 상황 파악
  • 1단계: 사실 확인
  • 2단계: 문제점 발견
  • 3단계: 근본 문제점 결정
  • 4단계: 대책 수립
  • 상해 종류 예
    골절, 동상, 부종, 찔림(자상),
    타박상(좌상), 절상, 찰과상,
    화상, 뇌진탕, 익사, 피부염
  • 🔀 헷갈리는 선지'떨어짐·끼임'은
    재해 발생형태, '골절·화상'은
    상해 종류입니다.

재해 발생형태 (산재 분류)
떨어짐, 넘어짐, 깔림·뒤집힘, 부딪힘,
물체에 맞음, 무너짐, 끼임,
절단·베임·찔림, 감전, 폭발, 화재 등

⭐ 기인물과 가해물

  • 기인물: 재해를 일으킨 근원이 된
    기계·장치·물체·환경
  • 가해물: 사람에게 직접 닿아
    피해를 준 물체·물질

재해 통계 계산(도수율·강도율 등)은
1과목 기출포인트 2번 주제 참고

⭐ 하인리히 방식

  • 총재해비용 = 직접비 + 간접비
  • 직접비 : 간접비 = 1 : 4
  • 직접비: 법적 보상비
    요양, 휴업, 장해, 유족, 장의비 등
  • 간접비: 인적·물적·생산 손실 등
    직접비 외의 모든 손실

예) 직접비 1,000만 원
→ 총재해비용 = 1,000 × 5 = 5,000만 원

⭐ 시몬즈 방식

  • 총재해비용 = 보험 코스트
    + 비보험 코스트
  • 비보험 코스트
    = A × 휴업상해 건수
    + B × 통원상해 건수
    + C × 응급조치 건수
    + D × 무상해사고 건수
    (A~D는 상해 정도별 평균 비보험 비용)
  • 사망·영구 전노동불능은 제외

버드 방식
보험비 1 : 비보험 비용 5~50 (빙산 원리)

콤페스 방식
총재해비용 = 개별 비용비 + 공용 비용비

🆕 보강 · 상해 정도 분류와 시몬즈 항목

⭐ 노동불능 상해 분류 (ILO)

  • 사망
  • 영구 전노동불능: 장해 1~3급
  • 영구 일부노동불능: 4~14급
  • 일시 전노동불능: 일정 기간 일을 못 함
  • 일시 일부노동불능: 일부 작업은 가능
  • 응급조치 상해: 응급처치 후 바로 복귀

시몬즈 상해 분류와 연결

  • 휴업상해: 영구 일부노동불능,
    일시 전노동불능
  • 통원상해: 일시 일부노동불능,
    의사 통원 조치
  • 응급조치: 20달러 미만 손실 또는
    8시간 미만 휴업
  • 무상해사고: 의료 조치 없는 사고
  • 하인리히 간접비 예
    시간 손실, 기계·재료 손실,
    생산 손실, 신규 채용·교육비

원주속도
V(m/min) = π × D(mm) × N(rpm) ÷ 1,000

예) D = 300mm, N = 1,500rpm
→ V ≈ 1,414m/min (약 23.6m/s)

📋 출제기준 3-2 프레스 및 전단기의 안전

방호장치 종류와 표시

  • 광전자식: A-1, A-2
  • 양수조작식: B-1, B-2
  • 가드식: C
  • 손쳐내기식: D
  • 수인식: E
🧠 연상 암기A 광 · B 양 · C 가 · D 손 · E 수 — '광양 가서 손 수(洗)하기' (광전자 · 양수조작 · 가드 · 손쳐내기 · 수인)

안전거리 공식 ⭐

계산 문제 단골입니다.

  • 광전자식
    D(mm) = 1.6 × (Tl + Ts)
    Tl: 손이 광선을 차단한 뒤
    급정지기구가 작동하기까지 시간(ms)
    Ts: 급정지기구 작동 후
    슬라이드가 정지하기까지 시간(ms)
    1.6: 손의 속도 1.6m/s
  • 양수기동식
    D(mm) = 1.6 × Tm
    Tm = (1/2 + 1/클러치 맞물림 개소수)
    × 60,000 ÷ 매분 행정수(SPM)

예) Tl + Ts = 60ms
→ D = 1.6 × 60 = 96mm

예) 클러치 4개소, SPM 200
→ Tm = (0.5 + 0.25) × 300 = 225ms
→ D = 1.6 × 225 = 360mm

방호장치 조건 (고시 확인 필요)

  • 양수조작식
    누름버튼 사이 내측거리 300mm 이상
    양손 동시 조작(0.5초 이내)
    한 손이라도 떼면 정지
  • 손쳐내기식
    SPM 120 이하, 행정길이 40mm 이상
    방호판 폭: 금형 폭의 1/2 이상
  • 수인식
    SPM 100 이하, 행정길이 50mm 이상
  • 광전자식
    1행정 1정지 기구(크랭크 프레스)에 사용
    행정 중 광선 차단 시 즉시 정지

금형 안전
상형과 하형 틈새 등 손가락이 들어가지
않도록 8mm 이하

작업시작 전 점검

  • 클러치·브레이크 기능
  • 크랭크축·플라이휠·슬라이드·
    연결봉·연결나사의 풀림
  • 1행정 1정지기구, 급정지장치,
    비상정지장치 기능
  • 슬라이드·칼날의 기능
  • 방호장치 기능
  • 금형·볼스터 상태
  • 전단기 칼날·테이블 상태

🆕 보강 · 클러치에 따른 방호장치 선택

  • 마찰식(행정 중 정지 가능) 프레스
    광전자식, 양수조작식 사용 가능
  • 확동식(핀) 클러치 프레스
    행정 중간에 멈출 수 없음
    → 광전자식·양수조작식 부적합
    → 양수기동식, 게이트가드,
    손쳐내기식, 수인식
  • No-hand in die 방식
    금형 안에 손을 넣지 않음
    안전금형, 자동 송급·배출장치,
    전용 프레스
  • Hand in die 방식
    손을 넣어야 하는 작업
    → 방호장치로 보호
  • 🔀 헷갈리는 선지슬라이드 작동 중
    정지할 수 없는 프레스에는
    광전자식을 쓰지 않습니다.

📋 출제기준 3-3 기타 산업용 기계 기구

급정지장치 조작부 위치

  • 손조작식: 밑면에서 1.8m 이내
  • 복부조작식: 밑면에서 0.8~1.1m
  • 무릎조작식: 밑면에서 0.4~0.6m
    (0.6m 이내)
🧠 연상 암기이름이 곧 높이: 손 1.8m 이내(손 뻗는 높이) · 복부 0.8~1.1m(배 높이) · 무릎 0.4~0.6m(무릎 높이)

급정지거리 ⭐

  • 표면속도 30m/min 미만
    → 앞면 롤러 원주의 1/3 이내
  • 표면속도 30m/min 이상
    → 앞면 롤러 원주의 1/2.5 이내
🧠 연상 암기느리면 1/3, 빠르면 1/2.5 — 빠를수록 더 미끄러지니 허용 거리도 길다 (기준 30m/min)

표면속도
V(m/min) = π × D(mm) × N(rpm) ÷ 1,000

예) D = 360mm, N = 50rpm
→ V = π × 360 × 50 ÷ 1,000 ≈ 56.5m/min
→ 30 이상이므로 1/2.5 적용
→ 원주 π × 360 ≈ 1,131mm
→ 급정지거리 452mm 이내

가드 개구부 간격

  • X < 160mm: Y = 6 + 0.15X
  • X ≥ 160mm: Y = 30mm
    (X: 위험점에서 가드까지 거리,
    Y: 개구부 간격)

🆕 보강 · 개구부 예제와 함정

  • 가드 개구부 예제
    X = 100mm
    → Y = 6 + 0.15 × 100 = 21mm
  • 급정지장치
    자율안전확인 대상 방호장치
  • 🔀 헷갈리는 선지급정지거리 기준은
    표면속도 30m/min에서 갈립니다.
    미만은 원주의 1/3,
    이상은 원주의 1/2.5 이내
  • 조작부는 손·복부·무릎으로
    나뉘며 높이가 서로 다릅니다.

📋 출제기준 5-1 비파괴검사의 종류 및 특징
  • RT (방사선투과)
    X선·γ선으로 내부결함 확인
    용접부 검사, 기록 보존 가능
  • UT (초음파탐상)
    초음파 반사로 내부결함·두께 측정
  • MT (자분탐상)
    강자성체의 표면·표면 바로 아래 결함
  • PT (침투탐상)
    표면에 열린 결함, 비자성체도 가능
  • ET (와류탐상)
    도체에 와전류를 유도해 표면결함
    (튜브·배관)
  • AE (음향방출)
    재료가 변형될 때 나오는 음향으로
    진행 중인 균열 감시 (가동 중 검사)
  • VT (육안검사): 가장 기본
🧠 연상 암기영어 첫 글자로: Radiography 방사선 · Ultrasonic 초음파 · Magnetic 자분(자석이라 강자성체만) · Penetrant 침투(표면 열린 결함) · Eddy current 와류 · Acoustic Emission 음향방출

자주 나오는 질문

  • 내부결함: RT, UT
  • 표면결함: MT, PT, ET
  • 비자성체 표면: PT
  • 가동 중 결함 진행 감시: AE

🆕 보강 · 방법별 장단점과 PT 순서

  • RT
    장점: 결과를 필름으로 기록·보존
    단점: 방사선 피폭 관리 필요,
    얇은 면상 결함은 놓치기 쉬움
  • UT
    균열 같은 면상 결함에 강함,
    한쪽 면만으로 두께 측정 가능
  • PT 순서
    전처리 → 침투 → 세척
    → 현상 → 관찰 → 후처리
  • MT
    비자성체(알루미늄·구리·
    오스테나이트 스테인리스)에는 못 씀
  • 설비진단 기법
    진동 분석(회전기계), 오일 분석,
    적외선 열화상
🧠 연상 암기PT는 전·침·세·현·관·후 — '전침 세 번 현관 뒤' (전처리 → 침투 → 세척 → 현상 → 관찰 → 후처리)
23소음·진동 방지 ➕
📋 출제기준 5-2 소음·진동 방지 기술
➕ 출제기준과 대조해 새로 보강한 주제입니다.

⭐ 소음 방지 대책

  • 발생원 대책
    저소음 기계로 교체, 소음기 설치,
    방음 커버, 방진(진동 차단),
    기계 정비·급유
  • 전파경로 대책
    거리 확보(거리 감쇠), 차음벽,
    흡음재, 음원 방향 바꾸기
  • 수음자 대책
    귀마개·귀덮개, 방음 부스,
    노출시간 단축

흡음과 차음

  • 흡음: 소리 에너지를 흡수
    (다공질 재료, 실내 반사음 감소)
  • 차음: 소리가 건너가지 못하게 막음
    (무겁고 밀도 큰 벽)

방음 보호구

  • 귀마개 1종(EP-1): 저음부터 고음까지
  • 귀마개 2종(EP-2): 주로 고음 차단
  • 귀덮개(EM)

⭐ 진동 방지 대책

  • 발생원: 가진력 줄이기, 회전체
    균형(밸런싱), 탄성 지지
  • 전파경로: 방진구(도랑), 거리 확보
  • 수진측: 방진장갑, 작업시간 제한

방진재 종류
금속 스프링, 방진고무, 공기 스프링,
코르크·펠트

🆕 보강 · 방진재 특징과 진동 전달

  • 금속 스프링
    저주파 차진에 좋음,
    감쇠가 거의 없음(공진 시 주의)
  • 방진고무
    모양을 자유롭게, 고주파 흡수에 좋음
    열·기름에 약함
  • 공기 스프링
    고유진동수를 낮게 조절,
    구조가 복잡
  • 방진 효과 조건
    진동수비(가진 ÷ 고유진동수)가
    √2 이상일 때 전달이 줄어듦
