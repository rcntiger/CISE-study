# 2과목_인간공학 및 위험성평가·관리

## 📊 출제 빈도

- **가장 많이**: 시스템 위험성 추정 및 결정 › 인체계측 및 체계제어 › 작업환경과 인간공학
- **자주**: 위험성 평가 › 인간요소와 휴먼에러 › 신체활동의 생리학적 측정법 › 체계설계와 인간요소 › 물리적 유해요인 관리 › 인간-기계체계
- **가끔**: 인간공학의 정의 › 작업공간 및 작업자세 › 작업측정 › 근골격계 유해요인 › 위험성 감소대책 수립 및 실행 › 근골격계 유해요인 관리 › 중량물 취급 작업 › 인간공학적 유해요인 평가

## 🔑 필수 암기 (2과목)

- 인간공학 목적: 안전성 향상·사고 방지, 능률·생산성 향상. 철학은 "기계를 인간에 맞춘다"(인간을 기계에 맞추는 게 아님).
- 휴먼에러: 실수(Slip, 의도는 맞고 행동이 틀림) · 착오(Mistake, 상황해석·목표 잘못) · 건망증(Lapse) · 위반(Violation).
- 행동 분류: Swain — 생략(omission)·실행(commission)·순서(sequential)·시간(timing). Rasmussen — 숙련기반·규칙기반·지식기반 (경험기반은 없음).
- 욕조곡선: 초기고장(감소) → 우발고장(일정, 일정 고장률) → 마모고장(증가).
- 직렬 R = R₁×R₂×…, 병렬 R = 1−(1−R₁)(1−R₂)…
- 지수분포 신뢰도 R(t)=e^(−λt), MTBF=1/λ. 병렬 n개 수명 = MTTF(1+1/2+…+1/n).
- FTA: 톱다운(Top-down), 연역적, 정량·정성 분석. 컷셋=고장 조합, 패스셋=고장 안 나는 조합(시스템 정상).
- FT 기호: 조합 AND(3입력 중 2개), 배타적 OR(동시 발생 시 출력 없음), 억제 게이트(조건), 우선적 AND(순서).
- HAZOP 가이드워드: No/Not(완전 부정) · More/Less(양 증감) · As well as(성질 증가) · Part of(성질 감소) · Reverse(역) · Other than(완전 대체).
- 조도 = 광도/거리². (광원 밝기에 비례, 거리 제곱에 반비례, 반사율과 무관) 반사율 = 휘도/조도.
- WBGT: 옥외(일사) = 0.7×자연습구 + 0.2×흑구 + 0.1×건구 / 옥내·무일사 = 0.7×NWB + 0.3×GT.
- 소음: 90dB 8시간, 5dB 증가 시 노출시간 절반. sone = 2^((phon−40)/10) → 소리가 2배 크게 들리려면 +10phon. 60dB 음보다 4배 크게 = 80dB. 음량 척도 = phon·sone·인식소음(PNdB). (HSI는 아님)
- 청력 손실: 4,000Hz 부근에서 최대(C5-dip). 차폐효과: 한 음 때문에 다른 음의 감도가 저하.
- 동작경제 원칙: 양손 동시 시작·동시 종료, 휴식 시간 제외하고 양손이 동시에 놀지 않게, 공구 기능 결합.
- 안전성 평가 6단계: 관계자료 정비 → 정성적 평가 → 정량적 평가 → 대책 수립 → 재평가 → FTA 재평가. (대책 단계에 "위험도 평가"는 아님)
- 정성적 평가 설계관계: 입지·배치·건조물·소방설비 / 운전관계: 원재료·중간제품·공정·수송·저장.

## 📘 이론 정리

### 1 인간공학·인간-기계 체계
- 체계 설계 6단계: 목표·성능 명세 → 시스템 정의 → 기본설계 → 인터페이스 설계 → 보조물 설계 → 평가. 기본설계에서 기능 할당·인간성능 요건 정의·직무분석·작업설계. 화면설계는 인터페이스 설계 단계.
- 인간 vs 기계: 인간 우위 = 관찰을 통한 일반화·귀납적 추리·예기치 못한 사건 대응·창조. 기계 우위 = 반복작업·고속·대량·정량적 정보처리.
- 연구 기준(적절성, 무오염성, 민감도, 신뢰성): 민감도 = 예상 차이점에 비례하는 단위로 측정.
- 시각 vs 청각 표시장치: 시각 유리 = 메시지 복잡·길다, 후에 재참조, 즉각 행동 불필요, 정보가 공간적 위치. 청각 유리 = 간단·짧다, 즉각 행동, 재참조 불필요, 암소.
- 양립성: 공간(스위치 위치-표시), 운동(레버 위=증가), 개념(색의 의미), 양식(청각 자극-음성 응답).

### 1-4 휴먼에러
- 실수(slip): 의도 O, 행동 X. 착오(mistake): 의도 자체가 잘못. 건망증(lapse): 기억 실패. 위반(violation): 규칙을 알고도 어김.
- 원인 수준: Primary(작업자 자신) · Secondary(작업 형태·조건) · Command(요구되는 것을 할 수 없는 상황).
- 방지: 인간공학적 설계, 페일세이프(fail safe)·풀프루프(fool proof, 사람의 실수에도 안전)·인터록.

### 2 위험성 평가
- FTA: 시스템 위험 분석에 연역적·정량적. 기대효과 = 사고원인 규명 감소, 간소화, 노력·시간 절감, 시스템 결함 진단. (시간에 따른 원인 분석은 효과 아님)
- 컷셋 구하기: AND는 곱, OR는 합 → 전개 후 흡수법칙(A+AB=A, A·A=A).
- 확률: AND = 곱, OR = 1−(1−p₁)(1−p₂). 부울: A·Ā=0, A+Ā=1, A+1=1, A·0=0.
- MTTF(부품) = 총 동작시간/고장 수. 1,000개×100,000h / 5 = 2×10⁷h.
- 위험분석 기법: PHA(예비, 구상 초기) · FMEA(고장모드, 하향식) · HAZOP(공정, 가이드워드) · ETA(사건수) · THERP(인간오류 정량). 
- 운용단계 시스템안전 작업: 변경 영향 분석·사고 조사·교육·점검 등. "생산시스템 분석 및 효율성 검토"는 오답.

### 3 위험성 감소대책 (ECRS)
- Eliminate(제거) · Combine(결합) · Rearrange(재배열) · Simplify(단순화). 공정이 복잡해 불안전 행동 유발 → Rearrange.

### 4 근골격계
- 부담작업: 하루 2시간 이상 같은 동작 반복, 시간당 10회 이상 손·무릎으로 반복 충격, 하루 10회 이상 25kg 이상 들기 등. 시간당 5회는 기준 미달.
- 유해요인조사: 3년마다 정기, 신설 사업장 1년 이내 최초, 신규 도입 시 수시.
- 작업 휴식: 휴식 R(분) = 작업시간×(E−5)/(E−1.5)  (E: 평균에너지소비량 kcal/분, 기준 5kcal/분).

### 5 물리적 유해요인 (소음·조명·온도)
- 조도 기준(작업면): 초정밀 750lux 이상, 정밀 300, 보통 150, 그 밖 75.
- 반사율 추천: 천장 80~90% > 벽 40~60% > 가구 25~45% > 바닥 20~40%.
- 국소진동 → 레이노병(손가락 창백·동통). 전신진동: 4~8Hz 공명.
- 점광원 조도: E=I/d². 3m에서 300lux → I=2,700cd → 2m에서 675lux.
- 소음 노출 허용(8h=90dB, 5dB 증가마다 절반): 95dB 4h, 100dB 2h, 105dB 1h, 110dB 30분.

### 6 인체측정·작업환경
- 설계 기준: 극단치(최대집단치: 출입문·통로·의자 앉은 높이 등 / 최소집단치: 선반 높이·조종 장치 거리) · 평균치 · 조절식(좌석 등).
- 출입문 높이 = 최대 집단 기준, 손이 닿는 위치 = 최소 집단 기준.
- 경계 신호: 300m 이상 장거리 = 1,000Hz 이하(저주파). 
- 정보량: 대안 수 n → log₂n bit. 절대식별 7개 → 약 2.8bit.
- 평균에너지소비량·산소소비량: 1L O₂ = 5kcal.

## 🔁 반복 출제 문제

문제 → 정답. 시험 직전엔 이 목록만 훑어도 됩니다.

- HAZOP 기법에서 사용하는 가이드워드와 그 의미가 잘못 연결된 것은? → Other than : 기타 환경적인 요인
- 인간공학에 대한 설명으로 틀린 것은? → 인간을 작업과 기계에 맞추는 설계 철학이 바탕이 된다.
- 동작경제의 원칙에 해당하지 않는 것은? → 공구의 기능을 각각 분리하여 사용하도록 한다.
- 어떤 소리가 1,000[Hz], 60[dB]인 음과 같은 높이임에도 4배 더 크게 들린다면, 이 소리의 음압수준은 얼마인가? → 80[dB]
- A작업의 평균에너지소비량이 다음과 같을 때, 60분간의 총 작업시간 내에 포함되어야 하는 휴식시간(분)은? → 13.3
- 인간 에러(human error)에 관한 설명으로 틀린 것은? → commission errors : 필요한 작업 또는 절차의 수행지연으로 인한 에러
- 다음 중 욕조곡선에서의 고장 형태에서 일정한 형태의 고장률이 나타나는 구간은? → 우발고장 구간
- 결함수분석법에서 path set에 관한 설명으로 옳은 것은? → 시스템이 고장 나지 않도록 하는 사상의 조합이다.
- 다음과 같은 실내 표면에서 일반적으로 추천반사율의 크기를 맞게 나열한 것은? → ㉠<㉢<㉣<㉡
- 차폐효과에 대한 설명으로 옳지 않은 것은? → 차폐효과는 어느 한 음 때문에 다른 음에 대한 감도가 증가되는 현상이다.
- 다음 중 일반적인 화학설비에 대한 안전성 평가(safety assessment) 절차에 있어 안전대책 단계에 해당되지 않는 것은? → 위험도 평가
- 다음 중 광원의 밝기에 비례하고, 거리의 제곱에 반비례하며, 반사체의 반사율과는 상관없이 일정한 값을 갖는 것은? → 조도
- 위험 및 운전성 검토(HAZOP)에서 사용되는 가이드워드 중에서 성질상의 감소를 의미하는 것은? → Part of
- FT도에 사용하는 기호에서 3개의 입력현상 중 임의의 시간에 2개가 발생하면 출력이 생기는 기호의 명칭은? → 조합 AND 게이트
- 산업안전보건기준에 관한 규칙상 작업장의 작업면에 따른 적정 조명 수준은 초정밀작업에서 ( ㉠ )[lux] 이상이고, 보통작업에서는 ( ㉡ )[lux] 이상이다.  → ㉠ : 750, ㉡ : 150
- 경계 및 경보신호의 설계지침으로 틀린 것은? → 300[m] 이상의 장거리용으로는 1,000[Hz]를 초과하는 진동수를 사용한다.
- A회사에서는 새로운 기계를 설계하면서 레버를 위로 올리면 압력이 올라가도록 하고, 오른쪽 스위치를 눌렀을 때 오른쪽 전등이 켜지도록 하였다면, 이것은 각각 어떤  → 레버-운동양립성, 스위치-공간양립성
- 섬유유연제 생산 공정이 복잡하게 연결되어 있어 작업자의 불안전한 행동을 유발하는 상황이 발생하고 있다. 이것을 해결하기 위한 위험처리 기술에 해당하지 않는 것은? → Rearrange(작업순서의 변경 및 재배열)
- 인간 기계시스템의 연구 목적으로 가장 적절한 것은? → 안전의 극대화 및 생산능률의 향상
- 의도는 올바른 것이었지만 행동이 의도한 것과는 다르게 나타나는 오류를 무엇이라 하는가? → Slip
- n개의 요소를 가진 병렬 시스템에 있어 요소의 수명(MTTF)이 지수분포를 따를 경우 이 시스템의 수명으로 옳은 것은? → MTTF×(1+1/2+⋯+1/n)
- 인간의 실수 중 수행해야 할 작업 및 단계를 생략하여 발생하는 오류는? → omission error
- 국소진동에 지속적으로 노출된 근로자에게 발생할 수 있으며, 말초혈관 장애로 손가락이 창백해지고 동통을 느끼는 질환의 명칭은? → 레이노병
- 연구 기준의 요건과 내용이 옳은 것은? → 민감도 : 피실험자 사이에서 볼 수 있는 예상 차이점에 비례하는 단위로 측정해야 한다.
- 어느 부품 1,000개를 100,000시간 동안 가동하였을 때 5개의 불량품이 발생하였을 경우 평균동작시간(MTTF)은? → 2×10⁷ 시간
- 다음 중 불(Bool)대수와 정리를 나타낸 관계식으로 틀린 것은? → A·Ā=1
- 일반적으로 인체측정치의 최대집단치를 기준으로 설계하는 것은? → 출입문의 크기
- 상황해석을 잘못하거나 목표를 잘못 설정하여 발생하는 인간의 오류 유형은? → 착오(Mistake)
- 태양광선이 내리쬐는 옥외장소의 자연습구 온도 20[°C], 흑구온도 18[°C], 건구온도 30[°C] 일 때 습구흑구 온도지수(WBGT)는? → 20.6[°C]
