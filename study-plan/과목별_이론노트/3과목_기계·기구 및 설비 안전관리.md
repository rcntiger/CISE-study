# 3과목_기계·기구 및 설비 안전관리

## 📊 출제 빈도

- **가장 많이**: 기타 산업용 기계 기구 › 운반기계 및 양중기 › 공작기계의 안전 › 기계의 위험 안전조건 분석 › 프레스 및 전단기의 안전
- **자주**: 산재분류 및 통계 분석 › 비파괴검사의 종류 및 특징 › 재해조사
- **가끔**: 안전점검·검사·인증 및 진단 › 안전시설 관리 계획하기 › 소음·진동 방지 기술 › 기계공정의 특수성 분석

## 🔑 필수 암기 (3과목)

- 위험점 6종: 협착점(왕복 운동 + 고정) · 끼임점(회전·고정) · 절단점(회전 날) · 물림점(두 회전체 맞물림) · 접선물림점(벨트·체인) · 회전말림점(회전축·커플링). 회전축·커플링 덮개 = 회전말림점 방호.
- 안전율 = 기준강도(인장강도)/허용응력. 허용응력 = 250/4 = 62.5N/mm².
- 연삭기: 지름 5cm 이상 숫돌 덮개 설치 / 작업 시작 전 1분 이상, 숫돌 교체 시 3분 이상 시운전 / 평형플랜지 지름은 숫돌 지름의 1/3 이상(150mm → 50mm 이상) / 숫돌 정면이 아닌 측면에서 작업. 원주속도 V=πDN/1000 (m/min), 300mm·500rpm → 약 471.
- 프레스: 작업 시작 전 점검 = 클러치·브레이크 기능, 크랭크축·플라이휠·슬라이드·연결봉 볼트 풀림, 1행정1정지기구·급정지장치·비상정지장치 기능, 방호장치 기능, 금형·고정볼트 상태, 전단기 칼날·테이블. (권과방지장치·압력방출장치는 오답)
- 프레스 방호장치(시험 기준): 손쳐내기식 120SPM 이하·행정길이 40mm 이상 / 수인식 100SPM 이하·행정길이 50mm 이상. "300SPM 이상(150SPM 이상)에 사용"은 오답. 확동식 클러치 프레스는 광전자식·양수조작식·가드식·수인식 모두 가능, 마찰(비확동)식은 광전자식·양수기동식 불가.
- 롤러기 급정지장치: 손조작 로프식(밑면 1.8m 이내) · 복부 조작식(0.8~1.1m) · 무릎 조작식(0.6m 이내). 어깨조작식 없음. 급정지 거리: 표면속도 30m/min 미만 → 앞면 롤러 원주의 1/3, 30m/min 이상 → 1/2.5.
- 아세틸렌 용접: 발생기 사용압력 127kPa(1.3kgf/cm²) 이하, 발생기실 = 바닥면적의 1/16 이상 배기통, 역류 방지 = 안전기(수봉식 등), 발생기에서 5m 이내 화기 금지. 아세틸렌 70% 이상 구리 사용 금지(동 합금 62% 미만).
- 보일러 방호: 압력방출장치(안전밸브) · 압력제한스위치 · 고저수위조절장치 · 화염검출기. 안전밸브 2개 이상이면 하나는 최고사용압력 이하, 다른 하나는 1.05배 이하. 프라이밍(비수)·포밍(거품) 원인: 과부하·수위 높음·불순물. 역화는 아님.
- 공기압축기 방호: 언로드밸브·압력방출장치·압력계. 수봉식 안전기는 아세틸렌 용접.
- 컨베이어: 비상정지장치·역전방지장치·이탈방지장치·덮개/울·건널다리. 역전방지장치 = 기계식(래칫·롤러·밴드·웜기어) / 전기식(전기 브레이크·스러스트 브레이크). 반발예방장치는 목재 둥근톱.
- 지게차: 안정도 — 하역 시 전후 4%·좌우 6%, 주행 시 전후 18%·좌우 (15+1.1V)%. 헤드가드·백레스트(마스트 후방 낙하 방지). 화물 하중 모멘트 W×a ≤ G×b.
- 와이어로프 폐기 기준: 이음매, 한 꼬임에서 소선 10% 이상 절단, 공칭지름 7% 초과 감소, 꼬임·변형·부식. 두 줄 걸이 장력 T=W/(2cosθ/2): 120°면 T=W.
- 크레인 풍속: 설치·해체·수리 10m/s 초과 작업 중지, 운전작업 중지 15m/s 초과.
- 양중기: 크레인, 이동식 크레인, 리프트, 곤돌라, 승강기. (클램쉘·어스드릴·지게차는 양중기 아님)
- 안전검사 주기: 크레인·리프트·곤돌라 설치 후 3년 내 최초, 이후 2년(건설현장 6개월). 프레스·전단기·압력용기 3년 내 최초 후 2년. PSM 확인 압력용기 4년.
- 비파괴 검사: 와류탐상(교류 코일), 초음파, 자분, 침투, 방사선. 인장시험은 파괴시험.
- 재해통계: 도수율 = 재해건수/연근로시간×10⁶ / 강도율 = 근로손실일수/연근로시간×1,000 / 연천인율 = 재해자수/평균근로자수×1,000 = 도수율×2.4. 영구 일부 노동불능 손실일수 = 장해등급 일수×(300/365).
- 시몬즈 방식: 총 재해코스트 = 보험코스트 + 비보험코스트(휴업·통원·응급조치·무상해사고 건수에 평균 코스트 곱). 하인리히 방식: 직접비:간접비 = 1:4.
- 중대재해: 사망 1명↑, 3개월 이상 요양 2명↑, 부상·질병 10명↑.
- 재해원인 분석: 통계적 = 파레토도(큰 순서) · 특성요인도(등뼈: 좌→우) · 클로즈분석 · 관리도. 기인물 = 불안전 상태에 있는 물체, 가해물 = 직접 상해. (선반에서 끼어 다침 → 기인물: 선반)

## 📘 이론 정리

### 1-2 기계의 위험·안전조건
- 방호장치 종류: 격리형(덮개·울) · 위치제한형(양수조작식) · 접근거부형(수인식·손쳐내기식 = 접근을 기계적으로 거부) · 접근반응형(광전자식) · 감지형.
- 안전화 3종: 외관상(덮개·색채) · 구조부분(재료·강도·안전율) · 기능적(오동작 방지·급정지, 인터록) · 작업의 안전화. 구조적 안전화 = 안전설계.
- 설비보전: 예방보전·사후보전·개량보전·보전예방. TPM(설비종합효율).

### 3-1 공작기계
- 선반: 회전 중 측정·청소 금지, 척 렌치 제거, 칩 브레이커·실드·척커버, 장갑 착용 금지, 긴 가공물은 방진구(둥근 막대 길이 > 직경 20배).
- 드릴: 장갑 금지, 일감은 바이스·클램프, 칩은 솔·브러시로 정지 후 제거, 척 렌치 제거 후 기동. 
- 밀링: 상향절삭 시 일감 고정 철저, 커터 컬럼 가깝게, 칩은 브러시, 측정은 정지 후, 백래시 제거장치는 절삭 시. 
- 셰이퍼: 램 말단 충돌·칩 비산·바이트 이탈 (척 핸들 이탈은 아님).
- 연삭숫돌 파괴 원인: 과속, 플랜지 지름 너무 작음, 숫돌 균열·내경 부적합, 측면 사용, 충격.

### 3-2 프레스·전단기
- 금형 설치·해체: T홈 안길이는 설치볼트 직경 이상. 안전블록은 금형 부착·해체·조정 시(수리는 규정 문구 아님).
- 방호장치 선택: 슬라이드 정지 위치가 상사점 ↔ 하사점 반복 → 광전자식·양수조작식(클러치 맞물림 방식 따라). 수인식·손쳐내기식은 행정수 낮은 곳.

### 3-3 기타 산업용 기계
- 보일러(압력용기)·아세틸렌 용접장치·롤러·산업용 로봇(울타리 1.8m 이상, 단 안전기준에 부합하는 경우 예외, 수리 시 기동스위치 잠금).
- 로봇 작업 시 이상 발견 → 즉시 운전 정지 후 관리감독자 보고.

### 3-4 운반기계·양중기
- 양중기 표시: 정격하중·운전속도·경고표시 (최대 인양 높이는 아님).
- 훅 해지장치(와이어로프 이탈 방지). 권과방지장치(와이어 2번째 주행 끝). 
- 이동식 크레인 안전율: 와이어로프 5 이상 / 근로자 탑승 10 이상.

### 2 재해·안전점검·인증
- 안전인증 대상 방호장치: 프레스 및 전단기 방호장치, 양중기용 과부하방지장치, 압력용기 압력방출용 파열판·안전밸브, 절연용 방호구·활선작업용 기구, 방폭구조 전기기계·기구. 롤러기 급정지장치·연삭기 덮개·동력식 수동대패 날접촉예방장치는 자율안전확인.
- 파열판 안전인증 추가 표시: 호칭지름·분출(파열)압력·분출용량 등. "분출차(%)"는 규정 표시사항이 아님(최다 출제 오답).
- 점검: 일상 · 정기 · 특별(신설·변경·수리·이상기상 후) · 임시.
- 안전점검 체크리스트는 위험성 높은 순서·긴급도 순.

### 4 안전시설 / 5 비파괴·진동
- 소음·진동: 진동 3요소 = 진폭·주파수·방향. 
- 와류탐상: 코일 유기전압 변화로 결함 검출.

## 🔁 반복 출제 문제

문제 → 정답. 시험 직전엔 이 목록만 훑어도 됩니다.

- 밀링 작업 시 안전수칙으로 옳지 않은 것은? → 강력 절삭을 할 때는 일감을 바이스에 짧게 물린다.
- 산업재해의 분석 및 평가를 위하여 재해발생건수 등의 추이에 대해 한계선을 설정하여 목표관리를 수행하는 재해통계 분석기법은? → 관리도(control chart)
- 다음 중 금형 설치·해체작업의 일반적인 안전사항으로 틀린 것은? → 금형을 설치하는 프레스의 T홈 안길이는 설치볼트 직경 이하로 한다.
- 연삭기에서 숫돌의 바깥지름이 150[mm]일 경우 평형플랜지 지름은 몇 [mm] 이상이어야 하는가? → 50
- 아세틸렌 용접 시 역류를 방지하기 위하여 설치하여야 하는 것은? → 안전기
- 회전 중인 연삭숫돌이 근로자에게 위험을 미칠 우려가 있을 시 덮개를 설치하여야 할 연삭숫돌의 최소 지름은? → 지름이 5[cm] 이상인 것
- 보일러에서 프라이밍(priming)과 포밍(foaming)의 발생 원인으로 가장 거리가 먼 것은? → 역화가 발생되었을 경우
- 산업안전보건법령상 프레스 작업시작 전 점검해야 할 사항에 해당하는 것은? → 1행정 1정지기구·급정지장치 및 비상정지 장치의 기능
- 와이어로프의 꼬임에 관한 설명으로 틀린 것은? → 랭 꼬임은 로프의 끝이 자유로이 회전하는 경우나 킹크가 생기기 쉬운 곳에 적당하다.
- 선반 작업에 대한 안전수칙으로 가장 적절하지 않은 것은? → 작업 중 일감의 치수 측정 시 기계 운전상태를 저속으로 하고 측정한다.
- 다음의 “보기” 재해사례에서 기인물에 해당하는 것은? → 선반
- 프레스의 손쳐내기식 방호장치 설치기준으로 틀린 것은? → 슬라이드 행정수가 300SPM 이상의 것에 사용한다.
- K형 베어링을 생산하는 경기도 안전사업장에 300명의 근로자가 근무하고 있다. 1년에 21건의 재해가 발생하였다면 이 사업장에서 근로자 1명이 평생 작업시 약 몇 → 3건
- 500[rpm]으로 회전하는 연삭숫돌의 지름이 300[mm] 일때 원주속도[m/min]는? → 약 471
- 산업안전보건법령상 중대재해의 범위에 해당하지 않는 것은? → 1개월의 요양을 요하는 부상자가 동시에 5명 발생한 재해
- 롤러기 급정지장치의 종류가 아닌 것은? → 어깨조작식
- 산업안전보건법령상 압력용기에서 안전인증된 파열판에 안전인증 표시 외에 추가로 나타내어야 하는 사항이 아닌 것은? → 분출차(%)
- 다음 중 금속 등의 도체에 교류를 통한 코일을 접근시켰을 때, 결함이 존재하면 코일에 유기되는 전압이나 전류가 변하는 것을 이용한 검사방법은? → 와류탐상검사
- 산업안전보건법령상 프레스기를 사용하여 작업을 할 때 작업시작 전 점검사항으로 틀린 것은? → 압력방출장치의 기능
- 지게차의 안정을 유지하기 위한 안정도 기준으로 틀린 것은? → 부하 상태에서 하역작업시의 좌우 안정도는 10[%] 이내이어야 한다.
- 재해원인 분석방법의 통계적 원인분석 중 사고의 유형, 기인물 등 분류항목을 큰 순서대로 도표화한 것은? → 파레토도
- 보기와 같은 기계요소가 단독으로 발생시키는 위험점은? → 절단점
